      How a photograph becomes a verdict.

      Detector
      YOLOv8n fine-tuned for 50 epochs at 640 px on the Coffee Leaf v5 dataset. The class keys live inside the checkpoint, so the weights and the label map cannot drift apart.
      Leaf isolation
      Two green indices — normalised green and excess green — are thresholded with Otsu's method and intersected, then cleaned with morphological opening and closing. That intersection is the crop returned with every detection.
      Runtime
      Serving {{ weights_name }} through {{ runtime }}. Ultralytics loads either backend behind the same interface, so the choice is a configuration value rather than a code change.
      Transport
      A Flask app factory with one blueprint. Images are decoded from a byte buffer, so nothing touches the filesystem, and results come back as JSON with the annotated image inlined.

      Where this falls short.

      A detector that only reports its best number is not something to trust a crop with.

      The boxes are loose

      mAP@50 is {{ metrics.map50 }}% but mAP@50-95 is {{ metrics.map50_95 }}%. The model rarely misses a lesion, yet its rectangles are wider than the lesion itself. Read them as “look here”, not as a measured area.

      One dataset, one collection

      Training used 3,992 photographs from a single Roboflow collection. Accuracy on other cultivars, altitudes or phone cameras is unknown rather than guaranteed.

      Not an agronomist

      The protocol text is generic guidance for each class. It knows nothing about your planting density, fungicide rotation, or resistance in your block. Confirm with an extension officer before spraying.
